# Maison-de-Lumiere
ini merupakan muara dari perjalan panjang kami selama di bangku 10 SMK ini, dimana perjalanan ini tidaklah mudah untuk kami. Melalui project akhir ini, kami berusaha menuangkan pemahaman kami ke dalamnya. Setiap tantangan adalah quest, dan setiap error adalah kesempatan untuk memperbaiki dan berubah menjadi lebih baik.
**teknologi yang digunakan**
HTML - Untuk struktur website
CSS - Untuk desain dan animasi
JS - Untuk logika dan interaktifitas
